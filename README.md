# 🚀 Startup Team Hub

A light-weight interactive team organisation hub using HTML5, CSS3 and Vanilla JS. Perfect for early stage startups to organise teams, keep track of how many people in each department and visualise their team structure using interactive circular elements.
---

## ✨ Features

Live Headcount Counter - Automatically calculate the total amount of members within your startup.
Interactive circular departments - Click/touch on any circular department card to filter and view the members within that department.
Startup Team Setup - 7 startup departments included:
Core Management (3 Founder Members Included (CEO, CTO, COO))
Full stack/Web Dev
UI/UX
Cyber Security/DevSecOps
AI/Automation
Growth/Sales
HR/Operations
Add/Remove members instantly - Easily add new members with custom roles or remove existing members without refreshing the page.
Modern Dark Design - Uses CSS variables, Flexbox and CSS Grid to create a modern responsive dark design.
---
## 🛠 Technologies Used

HTML5
CSS3 (Custom Properties, Flexbox, Grid)
Vanilla JS (ES6+, DOM manipulation)
